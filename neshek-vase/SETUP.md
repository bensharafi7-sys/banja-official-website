# נשק וסע – מדריך הקמה

המדריך לוקח בערך 20 דקות, ועושים אותו פעם אחת. הכול חינמי. לא צריך כרטיס אשראי.

| מה | איפה | עלות |
|---|---|---|
| האפליקציה עצמה (האתר) | GitHub Pages | חינם |
| נתונים וכניסת משתמשים | Firebase (של Google) | חינם (התוכנית Spark) |
| תזכורות ערב לפני המשמרת | GitHub Actions + Firebase Cloud Messaging | חינם |

---

## שלב 1 – יצירת פרויקט Firebase

1. נכנסים ל-<https://console.firebase.google.com> עם חשבון Google של הוועד.
2. **Create a project** → שם: `neshek-vase` → אפשר לכבות את Google Analytics → **Create project**.

## שלב 2 – הפעלת כניסה למשתמשים

1. בתפריט הצד: **Build → Authentication → Get started**.
2. בלשונית **Sign-in method** בוחרים **Email/Password**.
3. מפעילים רק את המתג הראשון (**Email/Password**) → **Save**.

> ההורים לא צריכים אימייל. הם נכנסים עם מספר טלפון וקוד אישי בן 6 ספרות שהוועד שולח להם. האפליקציה מתרגמת את זה מאחורי הקלעים.

## שלב 3 – יצירת מסד הנתונים

1. **Build → Firestore Database → Create database**.
2. מיקום: **me-west1 (Tel Aviv)** → **Next**.
3. בוחרים **Start in production mode** → **Create**.
4. עוברים ללשונית **Rules**, מוחקים את כל מה שיש שם, ומדביקים את כל התוכן של הקובץ [`firestore.rules`](firestore.rules) → **Publish**.

> הכללים האלה הם מה ששומר על הנתונים. הורה רואה את הלוח ומסמן רק את הנוכחות של עצמו, ורק ביום שבו הוא משובץ. כל השאר (שיבוץ, עריכה, קודים, דוחות) פתוח רק לחברי ועד.

## שלב 4 – חיבור האפליקציה ל-Firebase

1. בפרויקט: ⚙️ **Project settings** → למטה **Your apps** → לוחצים על סמל ה-Web `</>`.
2. שם: `neshek-vase` → **Register app** (בלי Firebase Hosting).
3. מופיע קוד עם `const firebaseConfig = { ... }`. מעתיקים את מה שבין הסוגריים המסולסלים.
4. ב-GitHub פותחים את הקובץ [`neshek-vase/config.js`](config.js) ← לוחצים על העיפרון (Edit) ← מחליפים את `firebase: null,` במה שהעתקתם, ככה:

```js
  firebase: {
    apiKey: "AIza...",
    authDomain: "neshek-vase.firebaseapp.com",
    projectId: "neshek-vase",
    storageBucket: "neshek-vase.appspot.com",
    messagingSenderId: "1234567890",
    appId: "1:1234567890:web:abcdef"
  },
```

5. **Commit changes**.

> לא נורא שהפרטים האלה גלויים. זה מזהה של הפרויקט ולא סיסמה. האבטחה מגיעה מהכללים בשלב 3.

## שלב 5 – העלאה לאוויר (GitHub Pages)

1. ממזגים את הענף `claude/neshek-vase-app-k1g083` ל-`main` (Pull request → Merge).
2. במאגר ב-GitHub: **Settings → Pages**.
3. **Source: Deploy from a branch** → Branch: **main**, תיקייה: **/ (root)** → **Save**.
4. אחרי דקה-שתיים האפליקציה זמינה בכתובת:
   **<https://bensharafi7-sys.github.io/banja-official-website/neshek-vase/>**
5. חוזרים ל-Firebase: **Authentication → Settings → Authorized domains → Add domain** → `bensharafi7-sys.github.io`.

## שלב 6 – חשבון הוועד הראשון

1. פותחים את הכתובת בטלפון. בפעם הראשונה מופיע מסך **״הגדרה ראשונה״**.
2. ממלאים שם, טלפון, ובוחרים קוד אישי בן 6 ספרות. זה החשבון שלך כחבר/ת ועד.
3. בתוך האפליקציה, בלשונית **הגדרות**:
   - **אימות מיקום:** עומדים ליד הפס הירוק ← **״המיקום שלי עכשיו״** ← **״שמירת הגדרות״**.
   - **חברי ועד:** ״הוספת חבר/ת ועד״ לכל אחד. נוצר להם קוד אישי שאפשר לשלוח בוואטסאפ בלחיצה.
4. בלשונית **הורים** ← **״ייבוא מאקסל״** ← בוחרים את קובץ ההורים (עמודות: שם, טלפון, שם הילד/ה, כיתה).
5. פותחים כל הורה ← **״שליחה בוואטסאפ״**. ההורה מקבל קישור, את מספר הטלפון שלו ואת הקוד האישי. אפשר גם להוריד ״רשימת קודים״ לאקסל.
6. בלשונית **שיבוץ** ← **״שיבוץ אוטומטי״**.

## שלב 7 (מומלץ) – התראה בערב שלפני המשמרת

**א. מפתח להתראות בדפדפן**
1. Firebase ← ⚙️ **Project settings → Cloud Messaging**.
2. למטה ב-**Web Push certificates** ← **Generate key pair** ← מעתיקים את המפתח.
3. ב-`config.js` מדביקים אותו בשורה `vapidKey: '...'` ← Commit.

**ב. הרשאה לשליחה האוטומטית**
1. Firebase ← ⚙️ **Project settings → Service accounts → Generate new private key** ← יורד קובץ JSON.
2. ב-GitHub: **Settings → Secrets and variables → Actions → New repository secret**.
3. שם: `FIREBASE_SERVICE_ACCOUNT`. תוכן: כל התוכן של קובץ ה-JSON ← **Add secret**.
4. אחרי שהסוד נשמר, אפשר למחוק את הקובץ מהמחשב.

כל ערב בשעה 20:00 (21:00 בשעון קיץ, אחרי צאת שבת) נשלחת התראה להורים שמשובצים למחרת ושהפעילו התראות באפליקציה (לשונית ״מידע״ ← ״הפעלה״). אפשר להפעיל את השליחה ידנית לבדיקה: **Actions → נשק וסע – תזכורות למשמרת → Run workflow**.

> **אייפון:** התראות עובדות רק אחרי שמוסיפים את האפליקציה למסך הבית (iOS 16.4 ומעלה).
> **גיבוי:** בלוח הבקרה של הוועד יש גם כרטיס ״תזכורות״ עם כפתור וואטסאפ לכל הורה שמשובץ מחר.

## שאלות נפוצות

**הורה שכח את הקוד?** לשונית הורים ← פותחים אותו ← ״שליחה בוואטסאפ״ שולח את הקוד שוב. ״קוד חדש״ מבטל את הקודם, למשל אם הקוד דלף.

**חבר ועד עזב?** הגדרות ← חברי ועד ← פותחים ← 🗑️. הגישה שלו לממשק הוועד נחסמת מיד.

**כמה זה עולה?** התוכנית החינמית של Firebase מספיקה בשפע לבית ספר: 50,000 קריאות ו-20,000 כתיבות ביום.

**ומה עם SMS?** כניסה עם קוד ב-SMS דורשת מעבר לתוכנית בתשלום ב-Firebase (Blaze), ועולה כמה אגורות לכל הודעה. הקוד האישי שהוועד שולח בוואטסאפ נותן את אותה רמת הגנה בחינם. אם תרצו בהמשך, אפשר להוסיף SMS.

**עד כמה בדיקת המיקום אמינה?** היא מונעת סימון ״הגעתי״ מהבית ומהווה הרתעה טובה. מי שמתעקש לזייף מיקום בטלפון יכול לעקוף אותה, ולכן הוועד רואה ליד כל סימון את המרחק מבית הספר.
